# Draft PRD: Recruitment Screening Helper

## MVP
- Upload a job description.
- Upload candidate CVs.
- Extract structured candidate profiles.
- Rank candidates from best to worst match.
- Generate a short explanation for each ranking.
- Export a shortlist of top candidates.
- Store candidate profiles for future job openings.

## User Roles
- Recruiter
- Hiring manager
- Admin

## Metrics
- Reduce manual CV screening time by 50%.
- Improve consistency of candidate evaluation.
