# Draft PRD: Field Inspection Web App

## MVP
- Responsive web app for technicians.
- Login with email/password.
- Create a new inspection report.
- Fill checklist fields.
- Add notes.
- Upload photos.
- Submit report to operations team.
- Export report as PDF.
- Admin can manage checklist templates.

## Assumptions
- Technicians have internet access while working.
- Desktop browser support is enough for the first release.
- Reports can be stored in a simple database.
