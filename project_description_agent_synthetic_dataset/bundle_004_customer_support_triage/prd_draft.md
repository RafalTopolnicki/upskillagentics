# Draft PRD: Customer Support Triage Assistant

## MVP Scope
- Ingest support tickets from Zendesk in real time.
- Classify each ticket by category, urgency, and sentiment.
- Automatically send responses for low-risk tickets.
- Escalate high-priority tickets to the correct team.
- Provide analytics dashboard for support managers.
- Support English, Polish, and German.

## Categories
- Billing
- Login/access
- Technical bug
- Feature request
- Cancellation
- Other

## Non-Functional
- Classification should happen within 5 seconds of ticket creation.
- Audit logs should be retained.
