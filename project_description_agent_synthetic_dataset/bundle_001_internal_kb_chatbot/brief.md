# Internal Knowledge Base Chatbot

We want to build an internal chatbot for employees to ask questions about company policies, onboarding, benefits, and engineering practices. The chatbot should answer based on a curated set of internal documents and provide links or citations to the relevant source material.

The first version should be simple and useful for employees. It should reduce repetitive questions to HR and IT. The system should be available in the browser and eventually in Slack.

Key stakeholder: Operations team. Primary users: all employees, especially new hires.
